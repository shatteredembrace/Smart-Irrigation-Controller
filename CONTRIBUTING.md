# Contributing

Contributions to this project are welcome through GitHub Pull Requests.

## Before Contributing

Please make sure that:

- Your contribution is your original work or you have the necessary rights to submit it.
- You do not include proprietary or copyrighted material belonging to another party.
- You do not include passwords, API keys, credentials, private keys, or other secrets.
- Your changes are relevant to the Smart Irrigation System.
- Your changes do not intentionally introduce security vulnerabilities or malicious functionality.

## Pull Request Process

1. Fork the repository.
2. Create a dedicated branch for your change.
3. Make your changes.
4. Test the changes where reasonably possible.
5. Provide a clear description of what you changed and why.
6. Submit a Pull Request.

The repository owner may review, modify, request changes to, reject, or merge any contribution at their discretion.

## Accepted Contributions

A contribution is not considered part of the project until it has been reviewed and merged by the repository owner.

By submitting a Pull Request, you acknowledge that an accepted contribution may be incorporated into this project and distributed under the project's applicable license.

You retain ownership of your original contribution unless otherwise agreed in writing.

## Code Quality

Please keep contributions consistent with the existing architecture and coding style.

For firmware contributions, clearly document:

- Hardware dependencies
- Pin assignments
- New libraries
- Configuration changes
- Changes to control logic
- Any new limitations or known issues

## Issues

Bug reports, technical discussions, feature requests, and other constructive feedback are welcome through GitHub Issues.

Please do not disclose sensitive information, credentials, or security vulnerabilities publicly.

## Scope

This project is primarily maintained as a personal engineering and portfolio project.

The project owner is not obligated to accept, maintain, or support any submitted contribution.
